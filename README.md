# 三國策士智庫市集 (Three Kingdoms Strategy Council & Skill Marketplace)

> 融匯三國頂級心智模型，為現代決策注入千年智慧。面臨困境，即刻召喚！

本專案是一個結合「東方水墨國風」與「現代科技儀表板」風格的三國策士智庫與 Skill 市集平台。當面臨職場抉擇、商業競爭、人際博弈或人生困局時，可隨時在市集中檢視、檢索並召喚不同思維流派的三國人物（諸葛亮、司馬懿、關羽、周瑜、郭嘉、賈詡、荀彧、魯肅、曹操、趙雲等），獲取其專屬局勢剖析、上中下三策，以及多軍師紅藍軍攻防辯論。

---

## ✨ 核心特色

1. **策士招募大廳 (Marketplace Hub)**：
   - 收錄 10 大名將策士完整心智模型（如關羽「千里走單騎之道」、司馬懿「鷹視狼顧忍戰術」、諸葛亮「隆中對矩陣」等）。
   - 支援按蜀、魏、吳陣營及破局、戰略、防守、自保、心理、組織等思維流派篩選。
   - 提供 Agent Skill / System Prompt 一鍵複製規格，可直接匯入各類 AI 助理或 IDE。

2. **單兵問策大帳 (Solo Consultation)**：
   - 結構化輸出：【觀局】（人物風骨直切盲區）、【上中下三策】（進取/穩健/警示與風險評估）、【72 小時落地行動清單】。
   - 支援預設常見疑難情境（如「被困舒適圈太久想出來闖蕩」）。

3. **赤壁廷議殿 (War Council Debate)**：
   - 挑選 2~3 位理念相剋之策士同場辯難（如「關羽 vs 司馬懿 vs 賈詡」或「諸葛亮 vs 司馬懿」）。
   - 實施紅藍軍攻防對決，互挑思維盲區，最後提煉【主公最終裁決令】。

4. **水鏡智慧分診室 (Water Mirror Triage)**：
   - 司馬徽坐鎮，一句話陳述難題，智慧分析格局屬性並推薦最佳策士。

5. **天機符節 (雙引擎架構)**：
   - 內建本地情境推演引擎，無須 API Key 即可開箱即用。
   - 支援自定義 Google Gemini API Key 切換為即時大模型推演。

## 🛠️ 技術棧

- **框架**：React 18 + TypeScript + Vite
- **樣式**：Tailwind CSS (自訂東方水墨暗黑主題、印章、毛筆字風)
- **圖標**：Lucide React

---

## 🚀 本地開發與啟動

```bash
# 安裝相依套件
npm install

# 啟動本地開發伺服器
npm run dev

# 建置正式生產版本
npm run build
```

啟動後於瀏覽器造訪 `http://localhost:5173/` 即可體驗。
